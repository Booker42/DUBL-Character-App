# DUBL 0.14 — changelog

## Главное в 0.14

- Полностью новая свободная рабочая область вместо обязательных трёх колонок.
- Отдельный режим **«Настроить лист»**: в обычной игре карточки не двигаются.
- Любую карточку можно свободно перемещать и независимо менять по ширине и высоте.
- Индивидуальные разумные minimum / preferred / maximum размеры для разных типов карточек.
- Snapping к сетке и соседним карточкам, alignment guides и запрет итогового overlap.
- Геометрия каждой карточки сохраняется у конкретного персонажа.
- Рабочая область автоматически увеличивается по мере раскладки карточек и является единственным обычным владельцем scroll.
- Контент может временно увеличить карточку без перезаписи размера пользователя.
- Хороший стартовый layout и команда сброса расположения.

## Что накопилось в промежуточных 0.13.x

### Персонажи и сохранение
- Добавлена библиотека персонажей вместо ручного поиска JSON.
- Быстрое переключение между последними персонажами.
- Создание, дублирование, удаление, импорт и экспорт из библиотеки.
- Дружелюбное расширение `.dubl`, остающееся переносимым JSON внутри.
- Автосохранение отдельных персонажей и перенос старого autosave.
- Карточки библиотеки получили одинаковую компактную высоту.

### Персонаж
- Добавлены портреты, хранящиеся внутри файла персонажа.
- Портрет увеличен и получил явные действия замены/удаления.
- «Размер» перенесён из профиля в «Характеристики».
- Добавлен индикатор состояния автосохранения.

### Умения
- Одно умение может использовать несколько характеристик.
- Tooltip бонуса показывает разбор формулы.
- Добавлено примечание к расчёту для решений мастера и нестандартных случаев.
- Исправлена вёрстка ранга/бонуса и уменьшен постоянный визуальный шум от ±.

### Плотность и layout
- Несколько итераций адаптивной плотности, отказ от вложенных scrollbar внутри карточек.
- Содержательно ограниченные min/max размеров вместо бесконечного растягивания конечных карточек.
- Исправлены feedback loops, возникавшие при одновременном auto-grow и responsive resize.
- 0.13.5–0.13.7 использовались как стабилизационные эксперименты, после которых 0.14 переносит геометрию карточек в независимый workspace и убирает взаимное влияние колонок.
