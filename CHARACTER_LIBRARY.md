# 0.13 — библиотека персонажей

## Что изменилось

- При запуске Дубль сначала показывает библиотеку персонажей, а не файловый диалог и не случайный autosave.
- Каждый персонаж автоматически хранится отдельным файлом во внутреннем каталоге приложения.
- Карточка в библиотеке показывает портрет, имя, концепцию и время последнего изменения.
- Из библиотеки доступны: открыть, создать, импортировать, дублировать, экспортировать и удалить.
- Меню «Персонажи» в рабочем листе показывает последние листы для переключения в один клик и пункт «Все персонажи…».
- Обычное сохранение и автосохранение работают прямо с библиотекой. Ручной выбор пути больше не нужен.
- Экспорт по умолчанию использует расширение `.dubl`; внутри это тот же переносимый JSON, поэтому старый формат не потерян.
- Импорт поддерживает `.dubl`, `.json` и `.bak`.
- Старый `autosave.json` версии 0.12.x автоматически импортируется при первом запуске 0.13, если библиотека ещё пуста. Исходный autosave не удаляется.

## Хранение

Linux: `$XDG_DATA_HOME/dubl-character/characters/` или `~/.local/share/dubl-character/characters/`.

Windows: `%LOCALAPPDATA%\\DUBL Character Sheet\\characters\\`.

Пользователь не должен работать с этими папками вручную; они нужны только для восстановления/диагностики.
