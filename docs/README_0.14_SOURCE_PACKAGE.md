# Дубль 0.14 для Linux

Нативный интерфейс Qt для правил «Дубль All Stars 3.69 REWORK». Браузер, сервер и подключение к интернету во время игры не нужны. Это приложение на Python с Qt; архив не является автономным ELF/AppImage с включёнными зависимостями.

## Запуск

Распакуйте архив, откройте терминал в папке приложения и выполните:

```bash
bash run.sh
```

Нужен Python 3.10 или новее. Если Qt отсутствует, первый запуск установит PySide6 в отдельную `.venv`; для этой установки нужен интернет. Проверенная среда: Python 3.12, PySide6 6.8.3. Скрипт принимает совместимые версии PySide6 6.x.

На Arch/CachyOS можно заранее установить системные Python и Qt:

```bash
sudo pacman -S python pyside6
bash run.sh
```

На Debian/Ubuntu, если создание окружения недоступно:

```bash
sudo apt install python3 python3-venv libxcb-cursor0
bash run.sh
```

Если Qt сообщает об отсутствующей системной библиотеке, её необходимо установить пакетным менеджером дистрибутива. При проблемах с плагином Wayland попробуйте `QT_QPA_PLATFORM=xcb bash run.sh` в сеансе с XWayland. Приложение проверено в среде Qt offscreen; запуск именно в вашем графическом сеансе CachyOS ещё не проверялся.

Необязательно: `bash install.sh` копирует приложение в пользовательский каталог и добавляет пункт меню «Дубль — лист персонажа». Права администратора для этой установки не нужны. Терминал при запуске из меню показывает установку зависимостей и возможные ошибки.

## Свободная рабочая область 0.14

Основной лист больше не привязан к трём колонкам. В обычном режиме карточки полностью стабильны. Кнопка **«Настроить лист»** включает отдельный режим компоновки: карточку можно перетащить за заголовок в любое место рабочей области и независимо менять её ширину/высоту.

Карточки магнитятся к сетке и соседям, показывают направляющие и не позволяют сохранить перекрывающееся расположение. У каждой карточки свои разумные минимальные и максимальные размеры. Позиции и размеры сохраняются для конкретного персонажа. Рабочая область автоматически расширяется и является единственным обычным владельцем прокрутки; внутри карточек scrollbar не используется для обычного листа.

Если открытая способность, заклинание или предмет требует больше места, приложение может временно увеличить карточку, не меняя сохранённый размер пользователя. Полный длинный текст остаётся доступен в отдельном просмотрщике. Подробности: `WORKSPACE_014.md`.

## Библиотека персонажей и сохранения

В 0.13 приложение больше не требует вручную искать JSON-файлы для обычной игры. При запуске открывается **библиотека персонажей** с портретами, именами, концепциями и временем последнего изменения. Из открытого листа меню «Персонажи» позволяет быстро переключиться на один из последних листов или вернуться к полной библиотеке.

Новый персонаж сразу создаётся во внутренней библиотеке. Изменения текущего листа автоматически сохраняются в отдельный файл персонажа. В Linux библиотека находится в `$XDG_DATA_HOME/dubl-character/characters/` или `~/.local/share/dubl-character/characters/`; на Windows — в `%LOCALAPPDATA%\DUBL Character Sheet\characters\`. Пользователю открывать эти папки не требуется.

На экране библиотеки можно создать, открыть, дублировать, экспортировать и удалить персонажа. Экспорт по умолчанию создаёт файл `.dubl` (внутри остаётся переносимый JSON); обычный `.json` также поддерживается. «Импортировать» принимает `.dubl`, `.json` и резервные `.bak`.

При первом запуске 0.13 старый `autosave.json` из версий 0.12.x автоматически переносится в библиотеку, если библиотека ещё пуста. Исходный autosave не удаляется и остаётся дополнительной резервной копией.

Для переноса из 0.9 экспортируйте персонажа в JSON и нажмите «Импортировать» в библиотеке. Импорт сохраняет исходные данные внутри `legacyArchive`, объединяет повторные покупки и сохраняет нераспознанные записи как свои. После импорта проверьте карточку «Проверка персонажа».

## Правила и границы автоматизации

Смотрите `RULES_AUDIT.md`: формулы, источники, расхождения и принятые решения. Не все ситуационные эффекты навыков и имплантов можно применить без контекста боя. Они доступны в описаниях; численные эффекты можно включить через «Поправки». Уровни школ магии хранятся отдельно, без выдуманной цены развития.

## Для разработки

- `dubl/model.py` — данные, импорт, сохранение.
- `dubl/engine.py` — расчёты и проверка требований.
- `dubl/widgets.py` — элементы Qt.
- `dubl/catalog.py` — каталог и описания.
- `dubl/app.py` — экраны и взаимодействия.
- `data/catalog.json` — справочные записи.
- `data/audit.json` — структурированный журнал сверки.

Проверка расчётов: `python3 -m unittest discover -s tests -v` из папки приложения. Проверка интерфейса: `QT_QPA_PLATFORM=offscreen python3 -m unittest discover -s tests -p 'test_ui.py' -v`.

Установка Qt: [официальная документация](https://doc.qt.io/qtforpython-6/gettingstarted.html). Пакет Arch: [pyside6](https://archlinux.org/packages/extra/x86_64/pyside6/).


## 0.12.2: стабильное адаптивное изменение размеров
Карточки и таблицы внутри них больше не создают вложенные полосы прокрутки. При недостатке места карточка переходит в более плотное состояние, а затем упирается в минимальный читаемый размер. Длинные списки показывают полезную выборку и кнопку «Показать все»; полный список увеличивает карточку, оставляя прокрутку только колонке.


## 0.12.3: профиль и размер
- «Размер» перенесён из карточки «Персонаж» в «Характеристики».
- В карточке «Персонаж» появился портрет: нажмите на рамку, чтобы выбрать изображение. Оно уменьшается до безопасного размера и хранится прямо в JSON персонажа, поэтому переносится вместе с листом. Управление портретом доступно через отдельное меню «Портрет»; правый клик по изображению также остаётся быстрым способом заменить или удалить его.

## 0.13: библиотека персонажей
- Новый стартовый экран с карточками персонажей и портретами.
- Быстрое переключение через меню «Персонажи» без файлового диалога.
- Каждый персонаж автоматически сохраняется отдельно во внутренней библиотеке.
- Создание, дублирование, удаление, импорт и экспорт из одного окна.
- Переносимый формат `.dubl` добавлен как дружелюбная оболочка над тем же JSON-форматом.
- Старый autosave 0.12.x автоматически подхватывается при первом запуске.

## 0.13.1: библиотека — одинаковые карточки

Исправлено растягивание карточек в неполной последней строке библиотеки персонажей. Все карточки теперь имеют одинаковую компактную высоту, а свободное место остаётся пустым под сеткой.

## 0.13.2: умения — несколько характеристик и чистая вёрстка

- В редакторе умения можно выбрать несколько характеристик. Все выбранные характеристики участвуют в расчёте бонуса.
- В колонке «Бонус» при наведении показывается полный разбор формулы: характеристики, ранг, поправки и бонусы от способностей.
- Добавлено поле «Примечание к расчёту» для нестандартных случаев и решений мастера; оно тоже видно в подсказке и полном описании.
- Старые листы с одним полем `attr` совместимы и автоматически продолжают использовать прежнюю характеристику.
- Исправлена ширина редактора ранга в таблице умений: кнопки `− / +` больше не залезают в колонку бонуса.



## 0.13.7: horizontal resize fine-tune

- Убраны жёсткие максимумы ширины трёх колонок: горизонтальный splitter снова использует доступную ширину окна.
- Компоновка карточек теперь меняется прямо во время горизонтального resize.
- Live-preview ширины не запускает auto-grow по высоте; окончательная подгонка контента выполняется после короткой паузы.
- Минимальный профиль использует более крупный портрет и меньше пустого пространства.
- Минимальная высота «Характеристик» увеличена, а узкая сетка теперь выбирает 4/2/1 колонки по фактической ширине вместо обрезания строк.
- Максимальная высота «Показателей» уменьшена до содержательно полезного диапазона.

## 0.13.6: bounded resizable cards

- Вернули свободное изменение высоты карточек, но у каждой карточки теперь есть собственные логичные minimum / preferred / maximum размеры.
- Во время перетаскивания меняется только геометрия: содержимое не перестраивается на каждом пикселе. Режим карточки выбирается один раз после отпускания мыши.
- Пользовательский размер хранится отдельно от фактической высоты. Большое открытое описание может временно увеличить карточку, а после закрытия она возвращается к выбранному пользователем размеру.
- Временное auto-grow ограничено максимальным размером карточки и не влияет на density state, поэтому не создаёт resize feedback loop.
- Длинные описания внутри листа не получают scrollbar: карточка растёт до разумного максимума, а полный текст остаётся доступен через «Ещё → Полное описание».
- Внутренние таблицы и текстовые области по-прежнему не скроллятся; единственный обычный вертикальный scroll принадлежит колонке.
- Высоты карточек снова сохраняются между запусками. Старые несовместимые высоты из 0.12–0.13.5 сбрасываются один раз, положение карточек и ширины колонок сохраняются.
- Добавлены логичные ограничения ширины трёх основных колонок, чтобы конечные карточки не превращались в гигантские пустые области.

## 0.13.5: стабилизация layout

- Убрано переключение плотности карточек по высоте — оно вызывало feedback loop и мигание при resize.
- В основном листе карточки теперь имеют только два адаптивных режима по ширине: обычный и узкий.
- Высота карточки определяется её видимым содержимым; вручную ужать карточку ниже читаемого размера больше нельзя.
- Убран вертикальный resize-handle у карточек.
- Для экономии места остаётся явное сворачивание карточки через `− / +`.
- Единственный обычный вертикальный scroll — scroll всей колонки, когда карточки физически не помещаются в окно.
- Таблицы, preview и описания внутри карточек не получают собственный scrollbar.
- Сохранённые вручную высоты из 0.12–0.13 сбрасываются один раз, но колонки, порядок, скрытые и свёрнутые карточки сохраняются.


## 0.13.4: повседневный UX

- Портрет в карточке «Персонаж» стал заметно крупнее и теперь является главным визуальным якорем профиля. Поля имени и концепции выравниваются по верхнему краю рядом с ним.
- Добавлено явное меню «Портрет» с действиями «Добавить / заменить» и «Удалить», чтобы управление изображением не зависело от скрытого правого клика.
- Редактор ранга в таблице умений стал read-first: кнопки `− / +` появляются только при наведении или фокусе, а в обычном состоянии список заметно чище.
- В шапке появился индикатор автосохранения: «Сохраняется…», «Сохранено» или «Ошибка сохранения».
- Меню «Персонажи» показывает до пяти последних персонажей, использует их портреты и отмечает текущий лист галочкой.
- Таблицы используют аккуратное сокращение длинного текста с многоточием там, где перенос уже не помещается; полный текст остаётся в подсказках.
